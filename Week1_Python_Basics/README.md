# What's in this folder
- `exercises.py` — 20 beginner Python exercises (lists, dicts, loops, functions, file I/O, basic OOP).
- `calculator.py` — Simple command-line calculator (add, subtract, multiply, divide).
- `todo_list.py` — Simple command-line to-do list app (add, view, complete, delete tasks).
- `file_parser.py` — Simple file parser that reads a text file and reports line/word/character stats.

# How to run
```bash
python exercises.py
python calculator.py
python todo_list.py
python file_parser.py
```
